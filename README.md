# Spider-Lily

Hand-gesture controlled 3D flowers in the browser, built with Three.js and MediaPipe hand tracking.

- `spider-lily/` — interactive spider lily: spread thumb and index finger to bloom, move your hand to move the plant (web version + TouchDesigner project).
- `lotus-gesture/` — a gesture-controlled 3D lotus on a glowing pond.

Run a web version with `python -m http.server 8642` inside its folder, then open http://localhost:8642 and allow the camera.
